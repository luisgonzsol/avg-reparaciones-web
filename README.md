# AVG Reparaciones C.A. — Web oficial

Web de AVG Reparaciones: reparación de electrodomésticos, embobinado de motores y tienda de repuestos en Caracas, Venezuela.

> Proyecto en desarrollo por fases. Este README se completará en la Fase 5: instalación, variables, copias de seguridad, cómo añadir productos y despliegue en Vercel.

## Puesta en marcha (desarrollo)

Necesitas tener instalado [Node.js](https://nodejs.org) 20.9 o superior.

```bash
npm install
npm run dev
```

Después abre http://localhost:3000 en el navegador.

## Comandos útiles

| Comando          | Para qué sirve                                                 |
| ---------------- | -------------------------------------------------------------- |
| `npm run dev`    | Arranca la web en modo desarrollo                              |
| `npm run check`  | Revisa el código: lint, tipos y tests                          |
| `npm run build`  | Genera la versión de producción                                |
| `npm run images` | Optimiza las fotos de `assets/` y las copia a `public/images/` |

Más detalles técnicos en [`CLAUDE.md`](./CLAUDE.md).
